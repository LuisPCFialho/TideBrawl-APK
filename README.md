# Tide Brawl - versões de teste

Aqui fica só o APK de teste mais recente do Tide Brawl (BananaWare), na secção **Releases**.

- Versão de teste: anúncios de teste da Google e loja local de teste, sem dinheiro real.
- Android 7.0 ou superior.
- O jogo verifica este repositório quando abre e avisa quando há uma versão nova.

Instalar: abrir a release mais recente no telemóvel, descarregar o `.apk` e autorizar "instalar apps desconhecidas" para o browser.
